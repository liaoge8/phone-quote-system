# 手机报价与价格管理系统

报价网站前端样本（静态页面）。

## 功能模块

- **报价台**：商品列表、五层价格链（首次虚拟价/正常价格/调价后价格/政策价/最终报价）、官网价与官网优惠后价格、国补价（官网价 x 15%，封顶 500 元，仅限官网价 ≤6000 元机型）
- **商品录入**：一次录入全部配置和颜色，支持政策解释、停产标记
- **情报中心**：爬虫+大模型样本界面、新入网登记台账（置顶）、吃瓜栏目
- **销量分析**：全国大盘、分系列激活量排行、单品跟踪、历史存档与同比对比

## 预览

直接用浏览器打开 `index.html` 即可（演示密码：`8888`）。
